# takyeonlee.com

Personal academic homepage of **Tak Yeon Lee**, Assistant Professor at [KAIST Industrial Design](http://id.kaist.ac.kr).

🌐 **Live site:** [www.takyeonlee.com](https://www.takyeonlee.com)

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home — bio & intro |
| `publications.html` | Research publications |
| `past.html` | Past projects |
| `teaching.html` | Courses |
| `joinus.html` | Join AI Experience Lab |
| `schedule.html` | Meeting schedule (Google Calendar) |

## Stack

Static HTML/CSS site hosted on **GitHub Pages** with a custom domain.

- No build step required
- Edit HTML files directly, then push to `main` to deploy

## Updating the site

```bash
# Edit files, then:
git add .
git commit -m "your update message"
git push
```

Changes go live at [www.takyeonlee.com](https://www.takyeonlee.com) within ~1 minute.
